АвтоПрокат. ЛР №8 и №9 (подключение к базе данных, авторизация)
================================================================

Проект продолжает приложение из ЛР №3–7. Новый проект не создавался.

ЧТО НУЖНО НА КОМПЬЮТЕРЕ
-----------------------
Обязательно:  .NET Framework 4.8 (входит в Windows 10 и 11).
Желательно:   служба PostgreSQL (любая версия 12 и новее).
НЕ нужно:     pgAdmin, NuGet, доступ в интернет.

Все библиотеки (Npgsql, System.Data.SQLite и их зависимости) лежат
в папке CarRental\lib и подключены ссылками. Восстанавливать пакеты
не требуется: проект открывается и собирается сразу.

ПЕРВЫЙ ЗАПУСК
-------------
1. Запустить CarRental.exe (или F5 в Visual Studio).
2. Откроется окно «Подключение к базе данных».
3. Вариант А. PostgreSQL:
   - указать сервер, порт, имя базы, пользователя и пароль;
   - нажать «ПРОВЕРИТЬ», появится результат проверки связи;
   - нажать «СОЗДАТЬ ТАБЛИЦЫ», программа сама создаст базу
     (CREATE DATABASE), таблицы cars и users и добавит начальные
     данные. pgAdmin для этого не нужен;
   - нажать «ПРОДОЛЖИТЬ».
4. Вариант Б. SQLite (если PostgreSQL не запускается):
   - выбрать «SQLite (запасное хранилище, сервер не нужен)»;
   - путь к файлу можно оставить по умолчанию (carrental.db рядом
     с программой);
   - «СОЗДАТЬ ТАБЛИЦЫ», затем «ПРОДОЛЖИТЬ».
   Программа работает одинаково с обоими хранилищами.
5. Если при нажатии «ПРОДОЛЖИТЬ» PostgreSQL недоступен, программа
   покажет причину и предложит переключиться на SQLite.

УЧЁТНЫЕ ЗАПИСИ
--------------
Создаются автоматически при первом создании таблиц:
   admin / Admin#2026   кабинет администратора (полные права);
   user  / User#2026    кабинет пользователя (просмотр, поиск,
                          карточка, Word, свой профиль).
Пароли хранятся в базе в виде PBKDF2-хеша с солью, в открытом виде
их нет ни в базе, ни в коде SQL.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
Не удаётся подключиться к PostgreSQL
   Проверить, запущена ли служба: «Службы» → postgresql-x64-NN.
   Проверить порт (обычно 5432), имя базы, пользователя и пароль.
   Если служба не стартует, работайте на SQLite: задание это
   позволяет, код приложения не меняется.

«База данных carrental не существует»
   Нажать «СОЗДАТЬ ТАБЛИЦЫ»: программа создаст базу сама.

Не стартует pgAdmin
   На работу программы это не влияет: приложение обращается
   к серверу напрямую через Npgsql, а таблицы создаёт само.

Ошибка про SQLite.Interop.dll
   Рядом с CarRental.exe должны лежать папки x86 и x64 с файлом
   SQLite.Interop.dll. Они копируются при сборке из CarRental\lib.

Настройки подключения сохраняются в файл connection.cfg рядом
с программой. Его можно удалить, чтобы начать с чистых значений.
